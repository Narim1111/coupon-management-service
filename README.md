# 🎟 Coupon Management Service

Бэкенд-сервис (RESTful API) для управления купонами и пользователями, разработанный на **Java** с использованием **Spring Boot** и реляционной базы данных **PostgreSQL**.

---

### Технологический стек
* **Язык:** Java 17+
* **Фреймворк:** Spring Boot
* **База данных:** PostgreSQL
* **ORM / Взаимодействие с БД:** Spring Data JPA, Hibernate, JDBC
* **Сборка проекта:** Maven

---

### Основной функционал
- Управление сущностями пользователей и купонов (CRUD-операции).
- Хранение и связь данных через реляционную БД PostgreSQL.
- REST API для взаимодействия с клиентом/фронтендом.

---
